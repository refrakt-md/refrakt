# v0.47.0 — Quotations and the content model

A content model reads groups, nested blocks and a trailing part, and reports what is missing
({% ref "SPEC-186" /%}); `section`'s header grammar is declared with it. On that, quotations get
roles a theme styles, instead of looks an author names ({% ref "SPEC-185" /%}): a quotation, a
featured quotation (`pullquote`), an excerpt and an epigraph, each with one shared attribution.

## Why

**Decoration was an author's choice, and Lumina's.** `pullquote`'s `default`, `accent` and
`editorial` name looks, and `plain` (withdrawn before v0.45.0 shipped) existed only to take Lumina's
blockquote decoration off again for the composed testimonial. SPEC-185 names what a quotation *is*
and leaves its look to the theme, as {% ref "SPEC-159" /%} did for surfaces.

**The content model could not say "these together".** An eyebrow only before a headline, an epigraph
only with its attribution, an attribution as a quote's last line: each needs a construct the flat
sequence lacked, so `section`'s real header grammar was hand-written code. SPEC-186 adds them.

## What lands

Nine items:

- **The content model** (SPEC-186):
  - {% ref "WORK-692" /%}: groups, and `position: last`;
  - {% ref "WORK-693" /%}: a nested model on a block field;
  - {% ref "WORK-694" /%}: `content-missing`, with the sweep;
  - {% ref "WORK-695" /%}: `section`'s header grammar declared.
- **Quotations** (SPEC-185):
  - {% ref "WORK-696" /%}: the `data-quote` role marker, and Lumina styling roles;
  - {% ref "WORK-697" /%}: `pullquote` as the featured quotation, with attribution, `excerpt`,
    `prominence` and the `quote` alias;
  - {% ref "WORK-698" /%}: the epigraph;
  - {% ref "WORK-699" /%}: the attribution as a quote's last line;
  - {% ref "WORK-700" /%}: the composed testimonial on a featured quotation.

## Deliberately not here

- **Renaming `pullquote` to `quote`.** The alias lands; the rename waits until it has been in use
  (SPEC-185 open question 2).
- **Promoting `content-missing` to an error.** It is a warning for this release (SPEC-186 D4.3).
- **Composing `recipe` and `comparison`.** SPEC-185 D3.4 decides how they treat `>` when they are
  composed; composing them is their own work.
