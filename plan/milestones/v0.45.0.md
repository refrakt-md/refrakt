# v0.45.0 — Steps and the list

A composition can number its items. Composition templates gain one tag, `{% group %}`, that
arranges what it holds as a row or a list, and `steps` becomes the first composition built on a
numbered list ({% ref "SPEC-156" /%}, {% ref "SPEC-161" /%} D5).

## Why

**A composition cannot produce a numbered list.** A native `steps` gets its numbers from
`sequence: 'numbered'` in its config, which stamps the `sequence` dimension on its `<ol>`. A
composition has no `sequence`, and its template cannot wrap an `each` slot's items in a list.

**A template's only row is a placed rune.** `{% bar %}` arranges as a row, but it carries
`data-rune`, which stops name resolution, so schema properties sourced inside it disappear.

**Numbers are not in the document.** A step's or a track's number is a CSS counter, so it cannot
be selected, copied, or placed by a layout ({% ref "ADR-029" /%}), and four runes hand-roll a
counter the dimension already provides, at different specificities ({% ref "BUG-024" /%}).

## What lands

Seven items:

- **Numbers:**
  - {% ref "BUG-024" /%}: the four vestigial per-rune counters are deleted;
  - {% ref "WORK-583" /%}: ordinals become DOM nodes;
  - {% ref "WORK-585" /%}: `steps` names its item container.
- **The list and the row:**
  - {% ref "WORK-676" /%}: `{% group %}` with `bar` and `list`, and the list contract's reset for
    a list with no sequence;
  - {% ref "WORK-677" /%}: `sequence` in the definition, and a list that stamps only its own
    items track.
- **Compositions and adoption:**
  - {% ref "WORK-678" /%}: `steps` composed;
  - {% ref "WORK-679" /%}: `Track` declares `metaFields` and `blocks`, and its byline is a variant.

## Deliberately not here

- **`feature`.** {% ref "SPEC-161" /%} D3 arranges its items through SPEC-156's arrangements, but a
  feature list is usually a grid, and SPEC-156 D1 leaves `grid` to its own spec. `feature` also
  needs `deflist` to read its term shapes.
- **`playlist` as a composition.** It needs the per-instance cascade for author-written children
  (SPEC-156 D8), which is a separate spec.
- **`carousel`** in `{% group %}`. It stays {% ref "ADR-018" /%}'s author-facing layout until a
  spec places it.
- **Replacing the plugin `steps`.** As in v0.44.0, the composition is compared, and swapping is
  decided after.
