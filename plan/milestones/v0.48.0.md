# v0.48.0 — Compositions go live

The first composed runes replace their plugin counterparts: `hero`, `cta` and `testimonial` move
from `site/staged-runes/` into the marketing plugin ({% ref "SPEC-181" /%} D5). Beside them, every
rune reference page gets a generated intro that says what the rune is and shows its source
({% ref "SPEC-187" /%}).

## Why

**The compositions have been reviewed, and staying staged costs.** Each staged rune is maintained
twice: its plugin transform, config and CSS, and its composition. Hero and cta showed no difference
on staging ({% ref "WORK-689" /%}); the testimonial has been approved. SPEC-181 takes them live one
at a time, as each review is accepted.

**Nothing on a reference page says a rune is a composition.** After going live, the pages look
exactly as before. A composition's definition is short Markdoc a reader can learn from and copy;
the intro marks it and opens it in a drawer. The same intro replaces the install hint written by
hand on 45 pages.

## Deliberately not here

- **`steps`.** It stays staged: whether the composition should keep the author's heading level and
  read a lone paragraph as a blurb is not decided yet.
- **A composition marker in the rune catalog and in `refrakt inspect` / `reference`.** They can read
  the same data afterwards.
- **A "customize this rune" guide**, copying a composition into a project's `runes.dir`.
