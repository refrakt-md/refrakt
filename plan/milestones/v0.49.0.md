# v0.49.0 — Rune docs, simplified

Every rune and docs page is cut back to the reader who opens it ({% ref "SPEC-193" /%}). A rune
page is for someone writing content: what the rune is for, how to write it, what it looks like,
what can change. Theme and implementation detail, hand-written copies of generated tables, plan
IDs and release history leave the pages; examples become live and minimal; the rune nav is
regrouped by what the author is doing.

## Why

**The docs grow and rarely shrink.** A sweep of `site/content/` (224 pages, about 142,000 words)
found the same few causes on page after page: detail for theme and rune authors on pages for
content authors, a second hand-written copy of what a generator already states (and copies already
wrong), citations a reader cannot open, and examples that bury their point.

## What lands

Eleven items:

- **Structure first:**
  - {% ref "WORK-711" /%}: categories stated once, regrouped into ten, and the nav follows them;
  - {% ref "WORK-712" /%}: one shape for a rune page, and the attribute table renders a rune's family.
- **What leaves the rune pages:**
  - {% ref "WORK-713" /%}: Output and implementation sections;
  - {% ref "WORK-714" /%}: hand-written attribute tables;
  - {% ref "WORK-715" /%}: plan IDs and release history, with a guard.
- **What the rune pages gain:**
  - {% ref "WORK-716" /%}: "How Markdown is read" and "when to use this", in place of the Section header boilerplate;
  - {% ref "WORK-717" /%}: live, minimal, real examples.
- **The docs:**
  - {% ref "WORK-718" /%}: concept guides to a Concepts group, fixtures out of the catalogue;
  - {% ref "WORK-719" /%}: getting started, and one shared adapter setup;
  - {% ref "WORK-720" /%}: theme page template, one home per topic, docs nav and terms.
- **Last:** {% ref "WORK-721" /%}: the longest rune pages, page by page.

## Sequencing inside the milestone

- WORK-711 first: it moves every rune page in the nav. WORK-718 follows it.
- WORK-712 next: WORK-713, WORK-714, WORK-716 and WORK-717 build on its template.
- WORK-715 and WORK-719 are independent of the rest. WORK-720 follows WORK-718.
- WORK-721 last, after WORK-713 to WORK-717.

## Deliberately not here

- **New content.** This milestone removes, moves and rewrites, adding only the "when to use this"
  lines and the "How Markdown is read" tables.
- **A generated rune nav.** `nav` cannot group by a frontmatter field; WORK-711 holds the nav to the
  categories with a test, and generating it is a follow-up.
- **A structure drawer** in the rune intro, beside Source.
