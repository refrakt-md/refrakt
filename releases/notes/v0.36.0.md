The findings v0.34.0 started producing now reach you: the dev server prints pipeline diagnostics on every content reload, `refrakt validate` checks your own project's config and content, and the MCP server can run the same check for an agent.

{% hint type="warning" %}
**Action needed:** `refrakt validate` used to check refrakt's own built-in config, so it always passed. It now validates your project and exits non-zero when a finding is at error severity. A CI step that runs it may start failing on problems that were always there.
{% /hint %}
