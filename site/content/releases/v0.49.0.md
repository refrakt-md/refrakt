# v0.49.0 · Rune docs, simplified

Released November 11, 2026 · [All releases](/releases)

Every rune reference page now has one shape: a generated intro, what the rune is for and when to use a neighbor instead, a basic example, a table of how it reads your Markdown, task-named sections with live previews, and one generated attribute table. Concept guides (surfaces, media guests, image schemes, motion, page sections, tint) have their own docs group, getting started is four steps, the adapter pages share one setup, and the docs cite no plan entities. Eleventy sites now render their runes. A `bg` overlay switches the text to match, drawers gain a `full` size, and a snippet inside a preview shows its tag as the source.

{% hint type="warning" %}
**Action needed:**

- **Content:** a `{% bg %}` with `overlay="dark"` or `overlay="light"` now switches the rune's text to light or dark, as a scrim does. Check pages that set their own text color over an overlay.
- **Content:** an inline `{% tint %}` reads the tokens `bg`, `surface`, `text`, `muted`, `primary` and `border`. `background` still works, with a warning; `secondary` and `accent` are now ignored, so write `text` or `primary` instead.
- **Eleventy:** `createDataFile()` reads the content directory and plugins from `refrakt.config.json`; drop `contentDir` and `plugins` from your data file. If your templates paginate under `alias: page`, rename it (for example to `entry`): `page` is Eleventy's own variable, and the pages render blank.
- **Themes:** a `size="lg"` drawer is now 64rem wide (it was 52rem).
{% /hint %}

## Changes

- **Eleventy sites render their runes.** `createDataFile()` rendered each page without the identity transform or syntax highlighting, and never loaded the plugins named in `refrakt.config.json`, so every rune was unstyled and a plugin rune such as `cta` failed to parse. It now loads the site through `createRefraktLoader`: the content directory, plugins and theme come from the config, and pages get the identity transform and highlighting. `contentDir` and `plugins` are ignored (with a warning); `configPath` and `site` select the config and site, and each page carries `highlightCss`. `createRefraktLoader` gains a `basePath` option.
- The Eleventy plugin now copies a package a theme stylesheet `@import`s by name (Lumina's `@refrakt-md/skeleton`) beside it and points the import there, since a browser cannot resolve a package name.
- The Eleventy scaffold and the packaged `templates/base.njk` are fixed: the data file imports the theme manifest with `with { type: 'json' }`, which Node requires; pages are paginated under `entry` rather than Eleventy's reserved `page`, so they are no longer blank; and nested URLs keep their slashes (`/docs/getting-started/`, not `/docsgetting-started/`).
- `create-refrakt`'s help and its generated template README now show `--framework sveltekit`; the `--framework svelte` they showed is rejected.
- **Text stays readable over a background.** A `{% bg %}` with `overlay="dark"` or `overlay="light"` now switches the rune's text to light or dark to match, as a scrim already did, unless a tint has set the color scheme. Over a scrim or a dark or light wash, Lumina shows muted text (a blurb) at full strength, as it does on a cover, so it no longer fades into the photo.
- **A figure's body sits flush with its edges.** A code block or table at the top or bottom of a `{% figure %}` kept its outer margin, leaving a gap above a code block that an image never had. The first child's top margin and the last body child's bottom margin are now cleared, as in a card; the caption keeps its own gap.
- **Drawer sizes.** `size="lg"` is now 64rem, wide enough for a 100-column line of code (it was 52rem); a narrower screen still caps it. A new `size="full"` takes the whole screen inside the gutter.
- **Inline tint tokens fixed.** A `{% tint %}` child rune now reads the six tokens the tint axis applies — `bg`, `surface`, `text`, `muted`, `primary`, `border` — the same names a named tint in theme config uses. It used to read an older list, so `text` and `muted` were dropped and `background`, `secondary` and `accent` were emitted under names nothing applied. `background` still works as an alias of `bg`, with a warning; `secondary` and `accent` are ignored, so write `text` or `primary` instead. `TINT_TOKENS` from `@refrakt-md/runes` is now the same list, and `@refrakt-md/transform` exports it.
- **Template bodies keep a function call on its own line.** In a `collection`, `aggregate` or `relationships` body, a line holding only a function call (`{% humanize($kind) %}`) at the start of a block tag such as `{% card %}` was joined to the tag's opening line when the body was captured, so the tag rendered as inline text and the content after it fell outside. It now stays on its own line.
- **Unpublished pages are not linked to.** Plan entities on a `draft: true` page register without a URL, so a backlog, decision log or activity feed shows them unlinked rather than linking to a page that is not built. An inline `{% link %}` with an empty `href` now renders its content unlinked, as the block form already did, rather than as `<a href="">`.
- **A snippet in a preview is the content when it is alone, and the source beside other content.** `{% preview %}` takes its first code block as the source to show, and a `{% snippet %}` becomes a code block before the preview sees it, so a preview holding only a snippet rendered nothing and never showed the tag. The snippet's code block is now marked (`snippet` on the fence): on its own it renders as the preview's content, and `source=true` shows the `{% snippet %}` tag. Beside other content, such as a sandbox, it is still that content's source, read from the file.
